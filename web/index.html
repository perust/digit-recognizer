Handwritten Digit Recognizer

Write digits across the strip, one after another. Each is read and collected as you move on to the next, and its ink fades once it has been taken. The network runs in this page — nothing is uploaded.

Write large, and leave a gap between digits.

    A convolutional network trained on MNIST, 99.5% on the test set. Digits are told apart by the gaps between them, then each is scaled into a 20×20 box and centred by its centre of mass, exactly as the training data was. Source on GitHub.
